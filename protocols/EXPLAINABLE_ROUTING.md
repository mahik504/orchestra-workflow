# Routing note

Name what this task loads. Leave the note off when nothing new is loaded.

```
Load: impeccable, gsap-core
MCP: playwright
Plugins: stitch
Libraries: gsap
Architecture: next
```

Print a line only when it has a value.

- **Load** is the skills for this job. A skill the human names is added unless it is missing or unsafe next to the route owner.
- **MCP** is a server this job will call. A catalog row is not a call.
- **Plugins** appear when this job uses one.
- **Libraries** are packages this job will add in the product repo.
- **Architecture** appears when a stack was chosen.
- **Missing** appears when a named tool is not on disk. Do not install it globally.
- **Dropped** appears when a named skill is unsafe beside the route owner.

The job table in `AGENTS.md` is the default skill list. Design domains annotate the capability the classifier already chose. They do not add a route.
