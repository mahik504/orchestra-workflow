# Visual governance

One conductor. Two locks. Critics are packets, not a second plan.

Live loop for PREMIUM / EXPERIMENTAL work a stranger will see:

```
Understand → Classify → Reference forensics (if named visual refs)
 → Design exploration → Visual contract DESIGN.md → Human contract approval
 → Golden stills → Human visual approval → Implement product UI
 → Real browser QA → Fresh-context review → Simplify → Final evidence → Remember
```

Details and the write lock: `DESIGN_LAB_PROTOCOL.md`.

## Two locks

1. **Contract.** LOCKED sections of `DESIGN.md` accepted. State: `CONTRACT_APPROVED`. Product `.tsx` / `.css` / `src/` / `app/` stay refused. Notes, `DESIGN.md`, `REFERENCE_BENCHMARK.md`, and `.orchestra/design-lab/golden-stills/` stay writable.
2. **Visual evidence.** Desktop still + mobile still, files on disk, human note. State: `APPROVED`. Then product UI may be written.

**A DESIGN.md is not visual evidence.** Tailwind tokens are not a still. A chat screenshot is not two viewports.

Silent skip of stills is a fail. Missing still files refuse `ApproveStills`. Bypass still needs a non-empty note.

## Named references

Open-ended PREMIUM (“surprise me”): **23** short cards, then one contract.

Named live site, screenshot recreation, “feel like X”, or an existing `REFERENCE_BENCHMARK.md`: **exactly 3** evidence-backed translations. Not 23 cards. Not a skip to one `DESIGN.md`.

A **pasted** `DESIGN.md` (or a named skill/MCP/pack that already *is* the contract) may skip the survey. Named *visual* references may not.

## Critics (not a second conductor)

| Role | Who |
| --- | --- |
| Conductor | The chat the human is talking to |
| Visual critic | One Antigravity specialist packet (`templates/design-critic-packet.md`) |
| Engineering critic | `fresh-context-review` from a clean context |
| QA | Playwright on **our** app + verification ledger |

Never two plans in parallel. A critic issues Keep / Rework / Kill / Park. It does not start a new loop.

## Kill switch

Every phase may issue:

- **Keep** — serves the approved stack; leave it
- **Rework** — direction stands; this surface must change
- **Kill** — fights the stack or is generic slop; remove it
- **Park** — useful later, not this story; stop touching it

“Skip orchestra” stands the contract down for the session. “Skip the lab” waives Design Lab for one task, recorded, never silent.

GetLayers stays `PURCHASE_PENDING`. Playwright stays on our app. Scrapling / Firecrawl stay reference-forensics tools. Do not install GSD, ECC, skill dumps, or MCP catalogs as core.
