# Presentation protocol

Route by need. Do not install three deck skills.

| Need | Use |
| --- | --- |
| College/internal | orchestra-docs markdown → export |
| Editable PPTX for a committee | OPTIONAL `presentation-skill` when orchestra-docs is not enough |
| HTML/animated demo deck | EXPERIMENTAL opendeck — registry only |
| Investor/hackathon | DESIGN.md visual world + screenshots from **our** running app |

Never fake metrics or contribution graphs. Ship-post voice: a concrete shipping voice (concrete, one lesson, named collaborators).
