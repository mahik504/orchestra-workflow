# Focus — 4.1.0

Run this with `prompt-forge` before classify. Source method: ADHD-style instruction sets (`ayghri/i-have-adhd`). Caveman shortness does not replace the brief.

## Do

1. Restate the job in one sentence, then the next action.
2. If the human already answered a question in this chat, do not ask it again.
3. Keep the technical detail the job needs. A short reply that drops a constraint is a failed brief.
4. When the work is large, name the current capsule and leave the rest closed.

## Do not

- Open a second plan.
- Shrink a security, data, or design decision so the message looks short.
- Load every specialist to feel thorough.
