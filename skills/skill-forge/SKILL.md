# Skill forge

Write the draft under `skills/_proposed/<name>/SKILL.md`.

Stop there. The user promotes it. Do not copy it into `skills/` and do not sync it.

Use `templates/custom-skill.md`. One job. A narrow description. A way to verify.

If the pattern has been seen fewer than three times and the user did not ask, do not draft.
