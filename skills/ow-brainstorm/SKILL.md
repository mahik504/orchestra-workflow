# Brainstorm

Use this when the human brings a product idea and has not asked for code yet. `grilling` still asks the hard questions. This skill writes the outcome down.

## Write

| Line | Content |
| --- | --- |
| User | Who has the problem |
| Job | What they are trying to finish |
| Constraint | Time, platform, or a thing that must not change |
| Why not | The honest reason this might be a bad build |
| Next | One next action, or "do not build" |

One idea per pass. A second idea goes in the parking line, not a second repository.

## Where it lives

A product idea that should last goes in the vault under `projects/<slug>/idea.md`. Do not paste the vault path into the public repo. Do not start the Design Lab from a brainstorm.
