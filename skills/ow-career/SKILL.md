# Career

Source method: Career Ops. The scraper is not installed. This skill edits a document from notes already on disk.

## Do

1. Use the role text the operator pasted and the notes they already wrote.
2. Keep claims that match shipped work. Cut a claim you cannot point at.
3. Hand back the file and stop. The operator submits.

## Do not

- Scrape a job board, an ATS, LinkedIn, or a company site for postings.
- Apply, message a recruiter, or create an account.
- Invent a title, a date, or a metric.

## Preconditions

- The operator pasted the role text and the notes already exist on disk.

## Procedure

1. The task's paths and acceptance line win.
2. Keep a claim only when it matches shipped work you can point at.
3. Hand back the file. The operator submits.

## Output

The edited CV or brief, with each new claim tied to a repo or a note.

## Verify

A claim without a source is removed before the file is returned.

## Skip

Skip for scraping, applying, or messaging. Those are not this skill.
