# Research

Use this when the answer depends on recent public discussion. Source method: last-30-days. `agent-reach` stays the skill for the operator's own public profiles.

## Do

1. Bound the search with a date. Say the bound in the answer.
2. Prefer a primary page over a recap of a recap.
3. Cite the page you actually opened. If two sources disagree, say so.
4. A repo evaluation names what the repo does and its license line. It does not install the repo.

## Do not

- Install `mvanhorn/last30days-skill`.
- Scrape, post, like, DM, or apply.
- Claim a page was read when the fetch failed. Say it was inaccessible.

Date the source. A claim about what people said recently needs the page title, the URL, and the day you read it. Web search is for a current doc or a fact this repo does not have. It is not a tour of trending lists.


## Preconditions

- The task names the files or the acceptance line.

## Procedure

1. The task's paths and acceptance line win.
2. Cite the page you opened. Date the note.

## Output

The change, the command that checked it, and what that command printed.

## Verify

Say the work is done only after that command has been run.

## Skip

Skip when the human says skip orchestra. Do not add a second conductor.
