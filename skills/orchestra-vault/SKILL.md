# Orchestra vault

Root: the private workspace created by `kit/init-workspace` (not this public GitHub repo).

## Read

Do **not** open the whole workspace. `routes.md` → one file → the app repo.

## Layout

| Path | What |
| --- | --- |
| `projects/<slug>/` | One product. Start with `idea.md`. |
| `templates/` | Copy, then fill |
| `memory/` | Global decisions. Career notes only if the human keeps them **private**. |
| `kit/` | Adapters |

## Write

Lasting notes only. Delete junk the same turn. Secrets never here.

## Git

The workspace may have a **private** remote. This public template is a different repo. Do not flip a populated workspace public if it contains personal files.
