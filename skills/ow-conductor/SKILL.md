## Routing

The route table is `docs/ROUTING.md`. Read that file when you classify. Name the skills, MCPs, plugins, and libraries that row loads. Omit that line when nothing new is loaded. A missing tool stops. It does not install itself.

One control loads `none`. Classify still opens `interaction-components`.

**fast** is a STANDARD job that names the file. **full** is PREMIUM or FLAGSHIP. **stand-down** is when the human says skip orchestra.

Open-ended PREMIUM is 23 cards. A named visual reference is 3 translations. A pasted DESIGN.md skips the survey and still owes stills.

Write DONE, FIXED, VERIFIED, PASSED, or SHIPPED only with observed evidence in the same message.


## Preconditions

- The task names the files or the acceptance line.

## Procedure

1. The task's paths and acceptance line win.
2. Name the route from docs/ROUTING.md. On a public profile, a new skill, or a visual direction, read Preferences hard hates first.
3. Do the work. A failed check is a lesson draft after a human yes, not a new skill.

## Output

The change, the command that checked it, and what that command printed.

## Verify

Say the work is done only after that command has been run.

## Skip

Skip when the human says skip orchestra. Do not add a second conductor.
