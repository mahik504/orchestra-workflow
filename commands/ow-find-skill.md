---
name: ow-find-skill
description: Search for a skill and recommend it. Install only if the human insists.
---

Load `ow-skill-advisor` and `find-skills`. Search with `npx skills find`. Check the license and whether a canonical skill already covers the job. Recommend. Install only after the human insists, and record that install. Do not pass `-g` or `-y` on a bulk add. Do not run `npx skills add --all`.
