# Optional MCP templates

`optional-servers.json` is the shadcn and Magic UI pair. Both are official CLIs. Add them to the host config for a product that uses those registries. Do not install them globally with a package manager.

Keyed servers stay empty until you supply the key in the host, not in this repo:

- 21st.dev
- Figma
- Upstash
- firecrawl

REA waits until Java is installed and the target is yours, a client's, a CTF, or open source. Fallow stays off until a product audit names it.

Copy the JSON into the host file. Do not commit the host file.
