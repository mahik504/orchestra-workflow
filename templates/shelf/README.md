# Shelf

These skills stay in the repository and off the host allowlist. `kit/sync-ides.ps1` copies `skills/` only.

| Folder | Why it is here |
| --- | --- |
| graphify | A local code graph. The pilot missed files. It is not the memory and not the map. |
| gsap-frameworks | Vue and Svelte. This stack's motion path is React. |
| gsap-plugins | Plugin catalog. Load a plugin page when a job names one. |
| gsap-utils | Helper catalog. The core, timeline, and scroll skills cover the default path. |
| obsidian-bases | Base views. The vault skill covers notes. |
| json-canvas | Canvas files. Not part of the default loop. |

`gsap-core`, `gsap-scrolltrigger`, `gsap-timeline`, `gsap-react`, and `gsap-performance` stay in `skills/`.
