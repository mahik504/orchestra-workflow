# Preferences (template defaults)

Copy into your private workspace and **replace** with your taste. These are anti-slop defaults, not a brand.

## Liked

- One type family with a real scale; tabular nums on data
- Motion with a job (state, hierarchy), 200–400ms, `transform` / `opacity`
- Hard edges or one consistent radius — pick a world and stay
- Dark UI that still passes contrast
- 3D only when it is the product (volume, scene, spatial data)

## Hated

- Inter + purple gradient as identity
- Nested cards, badge soup, fake activity charts
- Always-on kit MCP (21st, Aceternity, Magic)
- Skill dumps and `--all` installs
- Robot TTS and random UI whooshes on CRUD
- Cloning a reference site’s brand, assets, or source

## Thinking

- Import then tint; do not generate chrome from a blank rectangle when a named source exists
- College may assemble one kit; hiring and operator HUD stay original
- Token savings never cut design or security reasoning
