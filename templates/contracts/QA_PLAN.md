# QA plan

## Viewports

The desktop, tablet, and phone widths to capture.

## Interactions

The clicks, keys, and form path. Include empty, error, and focus.

## Console

The run fails on an unexpected console error.

## Network

The request that must succeed, and the failure the UI has to show.

## Accessibility

axe-core on the running page, plus one keyboard pass. Contrast is a number.

## Reduced motion

The capture with reduced motion turned on.

## Visual baseline

Golden stills after the contract is approved. Mask clocks, random ids, and canvases that are not the subject. Animated regions use a paused frame or a fixture.

## Thresholds

The budgets for this project. A failed budget is a failed check. A perfect universal score is not the goal.

## WebGL

When a scene exists: the fallback still, the context-loss state, and a note that a mock screenshot is not the scene.
