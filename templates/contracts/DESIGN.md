# Design contract

Fill every section. "None" is an answer. A blank section is not.

A different agent should be able to build this page from this file without seeing the chat.

## Brand identity

Who it is for, and the one trait a stranger should remember. Do not use a purple AI gradient as the brand.

## Visual direction

One direction. Name the references it learned from and the combination it refused.

## Reference analysis

Principles only: composition, type, grid, hierarchy, color relationship, spacing, interaction, scroll, light, camera, loading, and how it changes on a phone. Do not copy a site's files, logo, copy, or assets.

## Color tokens

Name the roles (ground, ink, accent, danger) and the hex or oklch values. State the text contrast as a ratio.

## Typography system

Display, text, and mono. Why this pair. The scale, the measure, and the fallback. Do not put Inter or Space Grotesk on a creative headline unless the product is a dense tool and this section says so.

## Spacing and layout

The space scale and the grid. One focal point per view.

## Responsive breakpoints

The widths that change the layout, and what actually changes. Not a shrunk desktop.

## Component system

The components this page needs. Reuse one that already exists before adding one.

## Surface treatments

Materials, borders, and depth. Glass, blur, and gradients need a job. Otherwise write "none".

## Interaction design

The one path a person takes, including empty, error, and focus.

## Motion language

The personality of the motion, in one sentence.

## Scroll behaviour

What is tied to scroll. If nothing is, write "native scroll".

## Cursor behaviour

Custom cursor, or "system cursor".

## 3D scene requirements

The scene's purpose, or "no scene".

## Shader specifications

The shader's purpose, or "no shader".

## Accessibility

Keyboard path, labels, contrast, and reduced motion.

## Performance budgets

The budgets for this page. Do not invent a perfect score. Include image weight and, when a scene exists, the DPR cap.

## Acceptance criteria

What a stranger can do, and what would make this contract fail.

## Visual references

Links or still paths, plus the principle taken from each. No trademarks as the design.
