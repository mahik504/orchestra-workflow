# Rule ledger

Always-on text is the part an agent cannot infer from the repo. The route table is `docs/ROUTING.md`. The long conductor procedure is `docs/CONDUCTOR.md`.

| Kept line | Failure it prevents |
| --- | --- |
| One conductor | A second harness opens its own plan |
| Capabilities are not the conductor | A skill or MCP starts installing itself |
| Route table is a file, not the adapter | Every chat pays for 30 rows it might not need |
| PREMIUM stills need a human yes | Product UI ships from a markdown contract |
| `skip orchestra` / `skip the lab` | The operator cannot stand the control plane down |
| No secrets, no `Co-authored-by: Cursor` | A public commit leaks a key or the wrong author |
| No `skills add --all` | A global skill install replaces the host |
| Recon only on own, client, CTF, or open source | A tool is pointed at someone else's app |
| Completion claims need observed output | DONE is written from intention |
| One motion runtime | A page loads GSAP and another engine |
| Zod at the boundary | A handler trusts the client body |
| A skipped check is not a pass | Visual QA treats "not applicable" as success |
| Stop at login, paywall, CAPTCHA, robots, 403, 429 | A scrape walks past a wall |
| Do not read `.env` or live MCP values | A hook or a log stores a key |
