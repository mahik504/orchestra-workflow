# Design

Start with `ow-design-intelligence`. Write the audience, one to three references, the type, the color, the layout, and which runtime owns motion. Hand that page to `taste-design`. One `DESIGN.md`.

A named reference gets three translations in the Design Lab, then stills. College work skips the lab unless the human says PREMIUM.

Galleries worth opening when you need a reference: Godly, Awwwards, SiteInspire, Lapa, Mobbin, Refero, Codrops. Write down the decision you took. Leave their assets in the gallery.

`ow-component-discovery` checks the product before it checks shadcn. One source for the pass.
