# One 3D scene

Load `ow-3d-engineering`. React Three Fiber when the page is React. Spline when the human will edit the motion visually. Blender for a film or a print asset, not as a browser runtime.

Ship a still first. Cap device pixel ratio from 1 to 2. Dispose the renderer on unmount. Reduced motion and a lost WebGL context keep the still. WebGPU only when the contract names it and WebGL2 still works.

GSAP owns scroll on the page around the canvas. The scene does not get a second scroll library.
