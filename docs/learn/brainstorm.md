# Brainstorm

`ow-brainstorm` writes options with a constraint each: who it is for, what it costs to build, what you would cut first. Pick one. File that choice where the product keeps decisions.

`grilling` is the pass that asks what the plan still assumes. Use it when the brief is a new product and the nouns are still soft. Then `domain-modeling` names the entities. `to-tickets` turns the plan into local work items.
