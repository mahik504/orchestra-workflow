# Research and ML

`ow-research` is for a public claim that needs a date and a source. Write the sentence, the URL, and the day you read it.

A paper loads `ow-research-paper` and `humanizer`. Check the DOI on Crossref before you keep a citation.

An experiment loads `ow-ml-experiment`. Record the data, the split, the metric, and the run you actually executed. A number you did not measure stays out of the README.
