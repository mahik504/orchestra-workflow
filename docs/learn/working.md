# Working

`ow-forge` writes a short brief when the job is open: intent, kind, route, acceptance, refs, constraints. A STANDARD fix that already names the file skips the brief.

`orchestra compile --task "..." --host cursor --json` prints the route, the skills, the model class, and the disclosure level. Load that list. A missing tool stops. It does not install itself.

PREMIUM visual work waits for one `DESIGN.md` and the stills. Execute still stops when a visual review needs a browser and Playwright is missing. `orchestra plan` records that gate and prints the manifest anyway.

Verify on the running app. Then a correctness pass, then a separate simplify pass. `agents/ow-fresh-reviewer.md` and `agents/ow-simplifier.md` are those two prompts.
