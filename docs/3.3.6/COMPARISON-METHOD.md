# Comparison method

Not run. No scores in this repository.

When a UI comparison is actually measured:

1. Three trials.
2. Three arms: raw host, this contract, and this contract with the design lab.
3. The same prompt. The judge does not know which arm produced the page.
4. Record what each arm produced. Publish a score only after the three trials agree.
5. Until then, `claim` stays `none`.

One private pair can be written as a note. A pair is not this study.
