# Supported Agents

You are running **Orchestra V3**.

Orchestra acts as an abstraction layer above your chosen AI coding assistant. The ecosystem is explicitly agent-agnostic. 

## Primary Adapters
- **Cursor:** Optimized for bulk component implementation, in-file diffing, and fast iteration.
- **Antigravity:** Optimized for visual QA (Playwright integration), complex architecture planning, and capability synthesis.
- **Claude Code:** Optimized for autonomous terminal execution, backend refactoring, and server-side auditing.

*Note: Any agent that can consume a JSON Execution Manifest can be plugged into Orchestra V3.*
