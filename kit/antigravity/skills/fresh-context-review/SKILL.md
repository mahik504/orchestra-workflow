# Fresh-context review

Job-loaded. Skip unless the human said a milestone is ready for review, pre-release, or named `fresh-context-review`.

This is a critic, not a planner. The conductor remains the chat the human is talking to.

## Skip

- The phase is not complete
- The request is to build or redesign from scratch
- The same chat that built the work is asked to rubber-stamp it without a fresh context

## Ask

What is wrong that the builder can no longer see?

Use a clean context. For visual work, require a running app or golden stills. Fill the verification ledger. Issue Keep / Rework / Kill / Park. Do not invent a second plan.
