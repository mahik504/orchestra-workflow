# Ship + career

When a project is **done enough to show** (assignment submitted, MVP usable, paper-ready README):

1. Stop. Remind: push to GitHub, then LinkedIn.
2. Write `projects/<slug>/ship-post.md` from `templates/ship-post.md`. Concrete, no fake stars/users.
3. Point at `memory/career.md`. Do not start the next product in the same breath.

Never use contribution-graph generators. Never typo-a-day commits. Real commits only.

Do not import LinkedIn “growth” skill packs. Profile README = a public repo named exactly the user's GitHub username.
