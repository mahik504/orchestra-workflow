# OW marks

Three monograms. The shipped default is `ow-mark-bars.svg`: a dark tile, an O as a bar, a W cut out of the second bar.

`ow-mark-ring.svg` is the light tile. `ow-mark-blocks.svg` is the dark tile with a brass block. Swap the default by copying another file over `ow-mark.svg`.

`social.svg` is 1280 by 640 for a GitHub social preview. GitHub does not accept that image through the API. Upload it yourself after exporting a PNG.
